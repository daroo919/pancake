# 🥞 팬케이크 드라이브 (Pancake Drive)

> **"학생들의 반짝이는 인디 게임 창고"**  
> 수수료 없이 자유롭게 인디 게임을 공유하고, 코드를 만나보며, 함께 팀을 꾸릴 수 있는 학생 개발자 전용 플랫폼입니다.

---

## ✨ 주요 기능 (Features)

### 1. 🚀 GitHub 스토리지 게임 연동
* 복잡한 빌드 파일 업로드 없이, 본인의 **GitHub 공개 저장소(Repository)**를 게임 스토리지로 직접 연결할 수 있습니다.
* 장르별(액션, 퍼즐, 슈팅, RPG, 아케이드 등) 분류 및 실시간 검색 기능을 제공합니다.

### 2. 🏢 스튜디오 & 크루 보드 (팀 매칭)
* **스튜디오 창설**: 나만의 개발 팀(스튜디오)을 만들고 멋진 배너 이미지와 대표 로고를 등록할 수 있습니다.
* **기술 스택 배지**: Unity, Unreal, Godot, Blender, React 등 팀이 사용하는 무기를 배지로 표현합니다.
* **다중 링크 지원**: 카카오 오픈 톡방, 디스코드, 깃허브 및 커스텀 링크를 동적으로 여러 개 추가할 수 있습니다.
* **팀원 모집 공고**: 프로그래머, 픽셀 아티스트, 기획자, 사운드 등 필요한 포지션의 팀원을 모집할 수 있습니다.

### 3. 💬 소통 및 피드백 시스템
* **게임 피드백 & 버그 제보**: 플레이어들이 남겨주는 따뜻한 응원 댓글과 대댓글, 그리고 버그 제보를 통해 게임을 발전시킬 수 있습니다.
* **개발자 방명록**: 마이 페이지와 개발자 프로필에서 서로 방명록과 대댓글을 남기며 소통할 수 있습니다.

### 4. 👤 개발자 마이 페이지
* 인증된 학생 개발자의 프로필과 커스텀 배너를 관리합니다.
* 내가 연동한 게임과 창설한 스튜디오를 한눈에 모아보고, 필요 시 연동 해제 및 스튜디오 폐지(삭제)를 관리할 수 있습니다.

---

## 🛠️ 기술 스택 (Tech Stack)

* **Frontend**: HTML5, Tailwind CSS (CDN)
* **Logic**: Vanilla JavaScript (ES6+)
* **Storage**: Browser `localStorage` (Client-side state management)
* **API**: GitHub REST API (Repository fetch integration)

---

## 🚀 시작하기 (Getting Started)

별도의 백엔드 서버 구축 없이 프론트엔드 파일만으로 간편하게 실행할 수 있습니다.

1. 이 저장소를 클론하거나 다운로드합니다.
2. `index.html` 파일을 웹 브라우저(Chrome 등)로 엽니다.
3. 우측 상단의 **GitHub로 로그인** 버튼을 통해 개발자 계정을 연동하고 나만의 게임과 스튜디오를 등록해보세요!

팬케이크 드라이브는 갓 구워낸 팬케이크처럼 따끈따끈하고 참신한 아이디어가 가득한 학생 개발자들의 놀이터를 지향합니다. 상업적인 부담 없이 순수하게 게임을 만들고 팀원을 모으는 즐거움을 느껴보세요!
